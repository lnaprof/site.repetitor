# Лендинг репетитора по английскому языку (портфолио-кейс)

Одностраничный сайт (лендинг) репетитора по английскому языку:
онлайн-занятия от A1 до C1, подготовка к ЕГЭ/IELTS, разговорный клуб,
Business English. На сайте есть форма сбора заявок на основе Яндекс Форм
(ответы пишутся в Яндекс Таблицу).

## Описание

Сайт создан как учебный/портфолио-проект. Все имена, логотип, фотографии
и личные детали являются собирательными образами; любые совпадения случайны.

## Возможности

- Адаптивная вёрстка (десктоп / планшет / мобильные)
- Анимации появления блоков при прокрутке
- Карусель отзывов с точками и свайпом
- FAQ (аккордеон)
- Мобильное меню (бургер) и плавающая кнопка «Записаться»
- Форма заявок — Яндекс Форма, встроенная в раздел контактов

## Технологии

- HTML5 / CSS3 (Flexbox, Grid, CSS-переменные)
- Vanilla JavaScript (ES5)
- Яндекс Формы (iframe-встраивание, авто-высота через embed.js)

## Запуск локально

Откройте `index.html` в браузере или запустите локальный сервер:

```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```

Сайт будет доступен по адресу: http://localhost:8080/
